## 신규 범위 설계에 지켜야 할 연결

- N-S04는 기존 주석 화면이다. N-F36~38의 지표/규칙/업종 패널과 N-F39~41의 원문·검출 상태를 통합하며 새 화면 ID를 임의로 만들지 않는다.
- 규칙 경고/주의/관찰, 미래 위험 사건 확률, 담당자 체크는 독립 상태다. 경고는 상단·원문 확인, 주의는 확인 항목, 미확보는 자료 없음/판정 보류로 표시한다.
- 원문→목차/주석 구간→교차참조→추출 항목/방향/한도·잔액→검수→요약/모델 특징을 추적한다. 검출/공시상 없음/미검출/추출 실패를 합치지 않는다.
- 3개년 비교와 패널 5개년 추세를 구분한다. 차트·최소 표본·가설 임계값은 미정/현직자 검토를 유지한다.
- DART 업종 매핑·복합 판정·수동 변경 사유/근거와 변경 후 재분석을 연결한다. 장비/물품 렌탈은 제외한다.

## 역할·진행

DB/산식·모델은 김동민, 수집·원문 파이프라인은 김동혁, 화면/API는 서종원, 지표/가설·가이드는 오준탁, 정답지/원문 QA는 최수인의 역할 초안이다. 세부 공수·승인자는 미정이며 WBS의 실제 기록을 따른다.
