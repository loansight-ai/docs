화면 설명

검토 흐름의 첫 단계. 기업을 식별하고 업종·기간·회계 범위를 확정해 이후 모든 화면의 기준으로 쓴다.

  1. 1

    검색과 업종 필터

    회사명·종목코드·DART 고유번호로 검색한다. 대상 4개 업종 필터와 제외 업종을 함께 보여 범위를 분명히 한다. 렌탈은 필터와 분석 어디에도 포함하지 않는다.

    N-F01N-R01
  2. 2

    검색 결과

    동명·유사 기업을 구분할 시장·고유번호·결산월을 표시한다. 제외 업종 기업은 “대상 아님”으로 남기되 선택할 수 없다.

    N-F01N-F02
  3. 3

    적용 기준 확인

    DART 업종코드 → 최장 접두 코드 매핑 → 업종·세부분류. 결산월, 연결/별도, 분석 기간, 정정 공시와 접수번호를 확인한 뒤 분석을 시작한다.

    N-F30N-R02N-R32N-U02
  4. 4

    업종 수동 변경

    사유와 근거 원문을 필수로 받는다. 변경 전후 기준을 기록하고 변경 기준으로 재분석한다. 권한·복합 비중은 미정.

    N-F30N-U15
  5. 5

    직접 입력 진입

    DART 조회가 안 되는 기업은 수치·출처·기준일을 직접 입력한다. 자동 수집값과 별도로 관리하고 충돌 시 표시한다.

    N-F04N-R06N-U08
