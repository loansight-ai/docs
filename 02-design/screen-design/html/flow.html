검토 흐름

좌측 내비게이션 순서와 같습니다. 어느 단계든 직접 이동할 수 있고, 상단 바의 기업·업종·보고서·회계 범위·기준일이 모든 화면에 고정됩니다.
N-S01

기업·업종 선택

  • 검색 · 4개 업종 필터
  • 업종 판정 · 세부분류
  • 결산월 · 연결/별도
  • 수동 변경 사유·근거
  • 직접 입력
N-S02

핵심 재무 요약

  • 영업이익 우선
  • 공통 핵심 5개 비율
  • 비율 5개 묶음
  • 상환능력
  • 업종 강조 지표
N-S03

실적 변동·현금흐름

  • 영업이익 증감 분해
  • 영업이익 vs 영업CF
  • 영업순환 · CCC
  • 예외 표시
  • 3개년 · 동종 비교
N-S04

주석·위험징후 패널

  • 경고·주의·관찰
  • 업종 우선 지표 · 5개년
  • 업종 맞춤 차트
  • 주석 자동 추출 · 4상태
  • 원문 근거 카드
N-S05

위험 사건 예측

  • 보류 (기본)
  • 12개월 확률 (검증 후)
  • 예측 대상 사건
  • 입력 영향 · 원문
  • 세 상태 구분
N-S06

관련 뉴스

  • 검수된 기사
  • 제외 기사
  • 검수 단계
  • 한계 · 링크 대체
N-S07

체크·검토 메모

  • 확인 항목 체크
  • 부실징후 17항목
  • 메모 초안 수정·복사
  • 버전 바
S04 → S07 주의·경고 징후와 미검출·추출 실패 항목이 확인 항목으로 자동 추가됩니다. 확인 완료는 담당자만 표시합니다.
S03 → S07 원문 확인이 필요한 현금흐름 항목(단기차입의 장기부채 상환 등)이 추가됩니다.
S05 ↔ S04 예측 보류 시 현재 징후는 S04에서 확인하도록 안내합니다. 징후 단계와 예측 확률은 별개 결과입니다.
