## 적용 기준

- 제조·건설·도소매·부동산 임대 4개 업종. 장비·물품 렌탈 제외.
- 연결(CFS) 우선, 없으면 별도(OFS) 전환·표시. 동일 추세에 회계 기준 혼합 금지.
- 상환재원·유동성/만기·재무구조·우발/부외·외부 평가·담보/회수 여력 6개 판단 관점.
- 경고·주의·관찰은 팀 가설과 담당자 확인 순서이며 공식 은행 등급이 아닙니다.
- 원문·기준일·추출/계산 상태·예측 제공/보류를 구분합니다.
