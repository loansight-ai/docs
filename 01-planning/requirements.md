# 요구사항 정의서

- 담당자 / 검토자: 미정
- 상태: 양식 준비
- 수정일: 작성 시 기록

기획 검토 후 실제 요구사항을 등록합니다. 아래 표는 작성 양식입니다.

## 기능 요구사항

| ID | 요구사항 | 사용자·상황 | 우선순위 | 완료·수용 기준 | 기능 ID |
|---|---|---|---|---|---|

ID 예시: `REQ-001`. 완료 기준은 확인 가능한 입력·결과로 작성합니다.

## 비기능 요구사항

| ID | 영역 | 요구사항 | 검증 방법·기준 |
|---|---|---|---|

성능, 데이터 갱신, 오류 처리, 접근 제어, AI 결과의 근거와 한계를 검토합니다.
