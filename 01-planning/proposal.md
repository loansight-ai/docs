v2.5 현재 서비스 반영

공통 5개 비율은 사분위 상대 위치를 제공하며 위험등급과 구별한다. 경계값·표본·95% 신뢰구간과 경계 부근 안내를 제공한다. OFS 표본·ECOS 통계와 업종합산 참고값의 의미를 구분한다. 소수 표본의 대표성과 결과 안정성은 제한 사항으로 표시한다.

주석 AI와 원문 연결

Gemini 요약 생성·저장 요약 조회·근거 원문 연결이 화면 코드에 존재한다. 현재 배포 상태는 Gemini 키 미설정이며 모델 표시는 gemini-3.6-flash다. 이는 실제 생성 성공이나 모델 제공자 유효성 검증 완료를 뜻하지 않는다. 규칙 기반 미리보기·AI 생성 초안·검수 전·오류/미생성 상태를 구분한다.

뉴스와 검토 저장

뉴스는 3개 매체 RSS 조회, 최근 1/3/6/12개월 선택과 새로고침 방식이다. 관련성 검수 완료로 표현하지 않는다. 체크·검토 메모의 브라우저 로컬 저장 방식은 같은 기기·브라우저 범위이며 사용자 간 공유·서버 영구 보존은 확인되지 않았다.

분석 도움말

별빛 라마는 화면 수치·규칙을 이용하는 도움말로 구현되어 있다. 생성형 챗봇으로 설명하지 않으며 원인이나 여신 결정을 확정하지 않는다.

추가 정합성 확인

선정 5개 지표와 기존 공통 참고 규칙이 함께 응답한다. 공통 규칙·선정 지표의 역할과 집계 관계는 추가 대조가 필요하다. 사건 경고 0건을 미평가와 동일하게 해석하지 않는다. 웹 조회 조건이 연도를 전달하더라도 재무 패턴 모델의 실제 제공 범위는 2025 OFS 연구 스냅샷이며 다른 연도 제공 여부는 미확인이다.

연계 문서 상태

이 개정은 기획안 v2.5다. 기존 PRD v0.0.8·요구사항 v0.0.9·기능명세 v0.0.8·WBS v1.6·테스트 v0.0.4에는 이전 확률 모델·v2.3 잔존 설명이 있어 전체 정합성 보완은 진행 중이다. 이 기획안 발행을 연계 문서 전체 최신화 완료로 기록하지 않는다.

프로젝트 목적 | 현업 문제와 서비스 목적 / 현직자 인터뷰에서는 영업이익을 우선 확인하며, 감가상각·현금흐름 정보 탐색과 기존 화면의 시각화·심사 항목 작성이 불편하다는 의견이 나왔다. 기업 관련 뉴스를 찾아볼 시간적 여유도 부족했다. / 핵심 재무 항목과 변동을 먼저 보여주고, 수치·원문 근거·추가 확인 사항을 검토 기록 초안으로 정리한다. 담당자는 초안을 수정·활용하고 항목별 미확인·확인 완료 상태를 관리한다. 최종 여신 판단과 내부 자료 확인은 담당자가 수행한다. / 초기 구현 범위 / 감가상각은 임대업 인터뷰에서 중요성이 언급된 항목이다. 모든 업종의 최우선 지표로 고정하지 않고 자산 구성과 사업 특성에 따라 강조 수준을 정한다. 주요 업종(제조업/도·소매업/건설업) 3개를 조사해 약 2주간 구현한다. / 부동산임대업은 주석 정리(32개사)까지 진행했고, 상환위험 징후 판정과 재무 패턴 분석에서는 제외했다. / 현금흐름표·감가상각 정보가 조회되지 않으면 API 범위, 계정 매핑, 보고서·주석의 위치를 확인한다. 자료 자체의 부재와 추출·조회 실패를 구분한다. / 수치적 변동과 사업상 원인 설명을 구분한다. 공시·주석을 우선 근거로 삼고 뉴스로 보완하며, 외부 자료로 확인하지 못한 부분은 담당자 추가 확인 항목으로 남긴다. / 데이터 분석과 차별화 / 실적 변동 기여도·업종 비교·이익과 현금흐름 차이 분석에 더해 두 가지 분석을 제공한다. 첫째, 상환위험 징후 판정이다. 2025년 별도재무제표(OFS) 자체 표본(제조 1,679·도소매 175·건설 64개사)으로 업종별 5개, 총 15개 지표 조합의 판정 기준을 만들었다. 이자보상배율 1배 미만·영업CF 음수·차입금이 있는데 EBITDA 0 이하는 주의(절대), 업종 표본의 불리한 사분위는 주의(상대), 그 사이는 관찰로 표시한다. 둘째, 비지도 학습 기반 '재무 패턴 분석'이다. 같은 지표로 Isolation Forest는 업종 비교 집단 안에서 재무 구조가 얼마나 이례적인지(이상도 백분위)를, k-means는 재무 패턴이 비슷한 기업 군집을 산출한다. 관측된 지표 수에 따라 5지표 모델·3지표 참고 모델·수치 분석 보류로 경로를 나누고 모델 버전을 구분한다. 여기에 업종마다 먼저 봐야 할 주석(건설 PF·조건부 의무, 제조·도소매 운전자본·자산 질)을 정리한 주석 요약을 붙여 담당자 확인 사항으로 연결한다. 연체 정답 자료가 없으므로 결과는 연체 확률이나 기업 종합등급이 아니다.
