## 프로젝트 목적

현업 문제와 서비스 목적

현직자 인터뷰에서는 영업이익을 우선 확인하며, 감가상각·현금흐름 정보 탐색과 기존 화면의 시각화·심사 항목 작성이 불편하다는 의견이 나왔다. 기업 관련 뉴스를 찾아볼 시간적 여유도 부족했다.

핵심 재무 항목과 변동을 먼저 보여주고, 수치·원문 근거·추가 확인 사항을 검토 기록 초안으로 정리한다. 담당자는 초안을 수정·활용하고 항목별 미확인·확인 완료 상태를 관리한다. 최종 여신 판단과 내부 자료 확인은 담당자가 수행한다.

초기 구현 범위

감가상각은 임대업 인터뷰에서 중요성이 언급된 항목이다. 모든 업종의 최우선 지표로 고정하지 않고 자산 구성과 사업 특성에 따라 강조 수준을 정한다. 주요 업종(제조업/도·소매업/건설업/부동산·임대업) 4개를 조사해 약 2주간 구현한다.

현금흐름표·감가상각 정보가 조회되지 않으면 API 범위, 계정 매핑, 보고서·주석의 위치를 확인한다. 자료 자체의 부재와 추출·조회 실패를 구분한다.

수치적 변동과 사업상 원인 설명을 구분한다. 공시·주석을 우선 근거로 삼고 뉴스로 보완하며, 외부 자료로 확인하지 못한 부분은 담당자 추가 확인 항목으로 남긴다.

데이터 분석과 차별화

실적 변동 기여도·업종 비교·이익과 현금흐름 차이 분석에 더해 재무·주석 결합 상환·연체위험징후 확률 예측을 도입한다. 소송·보증·담보 정보를 구조화해 재무지표와 결합하고, 재무지표만 사용한 모델과 비교해 추가적인 예측 가치를 검증한다. 예측 결과와 공시 원문을 담당자 확인 사항으로 연결한다. [추가] 은행의 자산건전성 분류(FLC)와 신용위험 평가 관점에 맞춰 업종별 상환·연체 위험징후 지표를 정의하고, 사업보고서 주석·XI장 원문에서 자동 추출한 근거(소송·보증·조건부 의무·담보·차입 만기)를 지표와 함께 보여준다.

## 프로젝트 수행 방향

1 대상 사용자와 초기 범위

주 사용자는 은행의 기업금융·여신심사 담당 행원이다. 초기 대상은 필요한 공시·재무정보가 확보되는 기업이며, 데이터 확보가 쉬운 상장사를 우선 검증한다. 코넥스는 상장시장 대상 검토에 포함하고 비상장 기업과 구분한다.

**적용 기준(요구사항 10/23 팀 결정):** 제조·건설·도소매·부동산 임대 4개 업종은 확정했다. 세부분류·기업·기간은 N-U02로 남기고 장비/물품 렌탈은 제외한다. 업종별 핵심 지표와 원문 확인 항목을 구분한다.

비상장·스타트업은 기업 목록과 DART 공시·재무 조회 가능성을 먼저 대조한다. 직접 입력은 기존 기능을 활용하되 입력 출처·기준일을 기록한다. 모든 비상장 기업의 자동 수집을 초기 제공 범위로 약속하지 않는다.

2 데이터 수집과 추적

OpenDART의 기업개황·공시검색·단일회사 전체 재무제표를 기본 수집원으로 사용하고, 공시서류 원본으로 주석과 경영진 설명을 확인한다. 기업 업종, 보고서·접수번호, 공시일, 수집일, 계정 식별 근거를 함께 저장한다. 공식 개발가이드는 아래 수행 도구 항목을 참조한다.

뉴스는 기업 식별과 실적 비교 기간을 기준으로 후보를 수집한다. 업종 평균의 외부 통계는 정의·회계 범위·시점이 맞는지 확인한 뒤 연동한다. ECOS 연계 가능성은 별도 검토하며 즉시 비교 가능한 자료가 있다고 가정하지 않는다.

모델 학습용으로 과거 여러 연도의 재무·주석과 상환·연체 위험 사건 이력을 결합한다. OpenDART 주요사항보고서 API(어음·수표 지급거절, 회생절차 개시신청, 채권은행 관리절차 개시 등)와 공시 원문을 1차 수집원으로 삼아 사건 발생일·접수번호를 대조하고, 제공 기간·대상 기업·누락 범위와 이용 조건을 확인한다. API에 조회 결과가 없다는 사실만으로 정상기업 라벨을 부여하지 않는다.

3 전처리와 품질 관리

연결재무제표를 우선 사용하되 없으면 별도로 전환하고 화면에 표시한다. 기간 비교 시 연결·별도, 통화, 단위, 보고 기간과 누적·당분기 기준을 맞춘다. 정정공시는 반영 여부와 버전을 남긴다.

표준계정 ID를 우선 매핑하고 계정명·주석으로 보완한다. 감가상각·무형자산상각·사용권자산 관련 금액은 구성과 중복을 확인한다. 결측과 0을 구분하고 추출 실패·비교 불가를 표시하며 자산=부채+자본, 합계·부호·단위를 검사한다.

4 정량 데이터 분석

영업이익 변동 기여도: 전기 대비 매출 증가 효과에서 매출원가·판관비 증가 효과를 차감해 금액 기여도를 계산하고 워터폴로 보여준다. 공시 구조에 따라 분해가 안 되는 차이는 기타·조정 차이로 남긴다. 이는 회계상 변동 분해이며 사업상 인과관계를 입증하는 결과는 아니다.

현금흐름 분석: 영업이익·영업활동현금흐름의 차이와 매출채권·재고·감가상각 등 관련 항목을 함께 탐색한다. 0 또는 음수 분모, 적자 전환 등에서는 단순 증가율·비율 대신 금액 차이와 상태 변화를 표시한다.

업종 비교: 동일 기간·회계 기준의 비교기업을 확보해 영업이익률, 부채비율, 현금흐름 등 분포와 중앙값을 살펴본다. 기능 검증 15곳은 논의 필요인 별도 표본이며, 업종별 3개 기업만으로 업종 전체를 대표한다고 주장하지 않는다. 비교 표본이 부족하면 순위·이상치 결론을 보류한다.

규칙 기반 확인 항목은 기존 시연 코드의 참고 기준에서 시작하되 업종별 근거와 현직자 의견으로 보완한다. 예를 들어 영업이익 30% 감소 등의 값은 팀의 임시 기준이며 은행 공식 심사 기준으로 제시하지 않는다.

4-1 업종별 핵심 지표와 상환·연체 위험징후 [추가]

5 AI 주석 요약과 추가 확인 안내

소송·보증·담보 제공 등 우발사항·약정 관련 주석을 찾아 유형, 상대방, 금액·통화, 진행 상태, 기준일, 원문 위치를 구조화한다. 지급보증 제공과 수취, 담보의 소유·제공 대상, 진행 중과 종결을 구분한다. 금액 미기재·추출 실패를 0으로 처리하지 않고 표·본문 중복, 단위와 부정 표현을 확인한다. 검증한 구조화 결과를 요약과 예측 입력에 공통 활용한다.

AI는 확보한 외부 자료의 추출·요약과 설명 후보 정리에 사용한다. 숫자와 비율은 코드로 계산한다. 요약에는 보고서명·주석명·원문 근거를 붙이고, 분쟁의 최종 결과나 손실 여부를 단정하지 않는다. 검색된 내용 없음과 해당 사항 없음을 구분한다.

예시 형식: 확인된 사실 / 원문 근거 / 해석과 한계 / 담당자 추가 확인. 내부 거래내역·담보 평가·상환 약정 등 외부 공시로 확인되지 않는 사항은 내부 자료 확인을 안내한다. 초기 서비스는 은행 내부 자료를 수집·전송하지 않는 범위로 설계한다.

5-1 상환·연체 위험징후 주석 자동 추출 기준 [추가]

공통 원칙: 해당 제목(주석 제목·XI장 소제목)부터 다음 주석 번호 또는 다음 소제목 전까지를 추출 범위로 한다. 당기/전기, 원고/피고, 제공/수취, 한도/실행잔액을 구분하고 원문 근거·단위·통화·접수번호(rcpNo)·목차 위치·주석 번호를 함께 저장한다. 일반 담보·차입약정은 우발부채로 자동 확정하지 않는다. 미검출은 ‘없음’으로 처리하지 않고, 원문에 ‘해당사항 없음’이 기재된 경우만 ‘공시상 없음’으로 별도 저장한다. ‘다른 장 참조’ 문장은 참조 위치를 따라가 다시 추출한다.

현재 원문 추출 시트(v0.0.1)는 제조·건설·도소매·부동산임대 4개 업종 각 10개 기업을 대상으로 한다. 분양률·미분양(건설 10곳 중 8곳), 작성기준일 이후 주요사항(임대 9곳), 담보 제공 자산(제조 6곳), 점포·매장 현황(도소매 6곳)은 미검출이 많아 검색어·추출 범위를 우선 보완한다. **적용 제외:** 원문의 렌탈 추가 수집 제안은 요구사항의 10/23 제외 결정에 따라 이번 범위에서 수행하지 않는다.

넓은 범위로 먼저 검색하고 관련성이 낮으면 경제 뉴스 등으로 범위를 조정한다. 멘토가 언급한 머니투데이·더벨은 후보 매체이며 수집 방식·활용 조건은 확인 후 정한다.

주석 입력 변수: 소송의 유무·건수·청구금액·진행 상태, 회사가 제공한 지급보증 금액, 담보 제공 금액과 대상, 한도·잔액 구분 등을 후보로 구성한다. 비교 가능한 금액은 총자산 대비 비율·전기 대비 변화로 변환하며, 회사 부담과 수취 보증을 구분한다. 소송·보증·담보의 존재 자체를 부실로 단정하지 않고, 예측력은 데이터로 검증한다. 미기재·자료 미확보·추출 실패도 구분해 기록한다. 업종별 추출 항목(PF 보증 만기 구간과 조건부 의무 유형, 1년 내 만기 차입 비중, 리스부채, 담보제공 비율, 기한이익상실 조항, 감사의견·신용등급 변화)을 후보 변수에 추가한다.

결합과 비교: 같은 기업·기간·검증 표본에 대해 재무지표만 쓰는 로지스틱 회귀 기준 모델과 재무·주석 결합 모델을 학습한다. 전처리·결측 대체·변수 선택·학습용 불균형 처리는 학습 구간 안에서 수행한다. 주석 요약을 모델에 그대로 맡기지 않고 검증된 구조화 항목을 수치 변수로 변환하며, 계산과 확률 산출은 예측 모델이 수행한다.

학습과 평가: 공시 시점에 알려진 자료만 입력하고 이후 위험 사건·정정공시·사후 사건이 유입되지 않게 한다. 학습 관측치의 12개월 결과가 검증 시작 전에 확정되도록 학습·검증·평가 구간을 나누고 기업 단위 중복 관측의 누출도 점검한다. 자연 발생 비율을 유지한 평가 표본에서 PR-AUC, 정밀도·재현율, Brier 점수·확률 보정을 비교한다. 학습 기업·관측치·위험 사건 건수와 업종 구성을 공개하고, 기능 검증용 기업 수(15개사 논의 필요)와 학습·평가 표본을 구분한다.

제공 결과: 추정 확률, 예측 기간·기준일, 모델 버전, 주요 입력 지표와 연결된 주석 원문, 추가 확인 사항을 함께 보여준다. 변수 영향은 예측의 설명으로 제시하고 상환·연체의 인과관계로 해석하지 않는다. 학습·검증 전에는 임의 확률을 실제 결과처럼 표시하지 않는다. 대출 승인·거절과 내부 등급은 담당자가 별도로 판단하며 뉴스는 초기 모델 입력에서 제외한다.

8 검증 설계

기능 검증 15곳·원문 정답지 5곳은 요구사항 v0.0.4 기준 논의 필요다. 실제 기업·기간·표본 수를 합의한 뒤 조회·계산·화면과 원문 정답지를 검증한다. 핵심 수치 일치율, 변동 분해 잔차, 결측 처리, 주석 추출 정밀도·재현율, 근거 없는 요약 건수, 뉴스 관련 기사 비율·누락을 기록한다. 주석 자동 추출 기준은 항목·업종별 정밀도·재현율과 미검출 원인(규칙 누락·공시 없음·형식 차이)을 나눠 기록한다.

모델 검증에서는 실제 위험 사건 라벨·예측 시점·추적 기간, 학습·평가 분리, 업종별 성능과 결측 영향을 확인한다. 동일 평가 표본의 재무 모델과 결합 모델의 지표 차이를 제시해 주석 정보의 추가 가치를 판단한다. 예측력 향상과 업무 시간 절감은 측정 결과로 확인하며 미리 성과로 단정하지 않는다.

수강생 비교 실험에서는 동일 난이도의 과제를 순서를 바꿔 수행하게 하고 검토 시간·누락 건수·메모 수정량을 비교한다. 현직자에게 핵심 화면과 확인 항목의 유용성을 확인한다. 결과는 측정 후 기재하며 소규모 실험을 은행 전체의 효과로 일반화하지 않는다.

9 서비스 구성과 발표

기업 검색·업종 선택 → 핵심 재무 요약 → 실적 변동·현금흐름 → 주석 확인 사항 → 상환·연체 위험징후·관련 근거 → 관련 뉴스 → 담당자 체크·검토 기록 초안 순으로 구성한다. 출처·기준일·비교 범위·확인 상태와 모델 검증 상태를 함께 표시한다. 주석 확인 사항 단계에 업종별 상환·연체 위험징후 패널(징후 단계·핵심 지표 추세·원문 근거)을 추가한다.

발표는 현업 문제 → 인터뷰로 확인한 니즈 → 업종별 재무·주석 검토 방식 → 실제 기업 시연 → 재무·주석 결합 상환·연체 위험징후 예측과 기준 모델 비교 → 검증 결과·한계·확장 계획 순으로 진행한다. 기대효과, 구현 상태, 실증 결과를 구분해 설명한다.

## 필수 기능 (주요 구현기능) 및
활용 방법 (기대효과)

필수 기능과 활용 방법

1. 기업 검색과 업종 표시 필터: 기업을 식별하고 업종·보고 기간·연결 또는 별도 기준을 확인한다.

2. 핵심 재무 대시보드: 영업이익을 우선 배치하고 업종별 중요 항목을 강조한다. 감가상각은 업종과 자산 구성에 따라 표시 비중을 정한다.

3. 실적 변동과 현금흐름 분석: 변동 금액·기여도, 이익과 현금흐름 차이, 주요 변동 항목을 보여준다. 비교 가능한 표본 범위에서 업종 분포를 함께 제시한다.

4. 공시 주석 AI 추출과 요약: 소송·보증·담보 관련 내용을 구조화하고 핵심 내용·금액·상태·원문·추가 확인 안내를 제공한다. 검증된 항목은 상환·연체 위험징후 예측 입력에도 사용한다.

4-1. 업종별 상환·연체 위험징후 패널: 업종별 핵심 지표, 징후 단계(경고·주의·관찰), 업종 맞춤 차트와 주석 자동 추출 근거를 한 화면에 보여준다. 징후 단계는 담당자 확인 순서용이며 건전성 분류·내부 등급을 대신하지 않는다. [추가]

5. 재무와 주석을 결합한 상환·연체 위험징후 예측: 재무지표와 구조화한 주석 정보를 결합해 향후 12개월 상환·연체 위험 사건 발생 확률을 추정한다. 재무지표 기준 모델과 성능을 비교하고, 예측 기준일·모델 버전·관련 지표·주석 원문을 함께 제공한다.

6. 심사 확인 항목과 체크: 시스템이 표시한 확인 필요 항목과 담당자의 확인 완료 상태를 구분한다. 예를 들어 현금흐름 변동·주석 위험 항목의 원문 확인 여부를 기록하고 미확인 항목을 모아 보여준다.

7. 검토 기록 초안: 핵심 수치·변동 내역·주석 근거·예측 결과·추가 확인 사항을 정리해 복사·수정할 수 있게 한다. 담당자는 검증 결과를 확인하고 내부 자료 판단과 최종 의견을 보완한다.

보완 기능

8. 관련 뉴스 요약: 기업과 실적 변동의 관련성을 확인한 기사만 선별해 날짜·출처·링크를 표시한다. 수집·품질 검증이 어렵다면 원문 링크 중심으로 제공한다.

향후 확장

업종 확대, 비상장·스타트업 지원, 외부 업종 통계 연계, 리포트 PDF 출력, 지점별 운영 체계는 핵심 기능 검증 후 추진한다. 상환·연체 위험징후 예측은 이번 개발 범위에 포함하며, 후속 단계에서는 표본·업종 확대와 추가 변수·모델 비교를 통해 개선한다.

기대효과와 산출물

재무·주석 탐색과 검토 기록 작성 시간을 줄이고, 미확인 항목과 위험 근거를 빠르게 파악하도록 돕는다. 업무 개선과 예측 성능은 비교 실험·모델 평가로 확인한다.

산출물은 웹 시연 서비스·소스·실행 안내, 업종별 항목 정의, 재무·주석·위험 사건 라벨 명세와 전처리 기록, 모델 학습·평가 코드와 비교 보고서, 원문 대조 정답지·검증 보고서, 발표자료·시연영상이다. 업종별 위험징후 지표 정의서와 주석 자동 추출 기준(검색어·추출 범위·저장 항목) 명세를 추가한다.
