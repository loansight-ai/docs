## 기획안 v2.5 · 2026.11.04

선정 지표의 검토 구분: 우선은 해당 업종에서 먼저 검토할 지표, 보조는 우선 지표와 주석의 해석을 보완할 지표, 조건부는 원금액 확보·분모·사업모형 등 적용 조건을 확인한 뒤 해석할 지표다. 조건을 충족하지 못하면 보류 또는 해당 없음 사유를 표시한다. 관찰까지는 표본 경계 등의 제약으로 현재 기준에서 주의(상대) 단계까지 구분하지 않는다는 뜻이다. 이 구분은 위험등급·가중치·구현 완료 순서가 아니며, 우선이라고 개별 적용 조건을 생략하지 않는다. 기존 표의 우선·보조·조건부 배정은 유지하며 지표별 적용 조건의 상세 확정은 추가 확인 사항이다.

2026.11.04 기준 현황 (계획 일정과 별도): 웹 베타 v1.5.3 배포·HTTP 인증 접속, OpenDART 우선·DB 보충과 ECOS 설정 응답을 확인했다. DB 원본 기준일은 2026-10-31, 웹 변환일은 2026-11-03이다. 극동유화 2025 OFS 기업 분석 응답을 확인했다. 이전 11/03 극동유화·동일금속 재조회는 정상 응답이었으나 전체 기업·화면의 완료 근거로 확대하지 않는다. 현재 Gemini 키는 미설정 응답이며, AI 주석 기능은 규칙 기반 미리보기와 생성 요약을 구분한다. 남은 확인: 전체 화면 클릭·정렬·저장·복사, 공시 원문 수치 대조, AI 실제 생성, 사건 경고 미평가/연도별 선정 지표 보류 조건, 뉴스 관련성, 배포 안정성. 11/05 09:00 제출은 기존 계획이며 실제 접수·제출 완료는 미확인이다.

### v2.5 현재 서비스 반영
공통 5개 비율은 사분위 상대 위치를 제공하며 위험등급과 구별한다. 경계값·표본·95% 신뢰구간과 경계 부근 안내를 제공한다. OFS 표본·ECOS 통계와 업종합산 참고값의 의미를 구분한다. 소수 표본의 대표성과 결과 안정성은 제한 사항으로 표시한다.

### 주석 AI와 원문 연결
Gemini 요약 생성·저장 요약 조회·근거 원문 연결이 화면 코드에 존재한다. 현재 배포 상태는 Gemini 키 미설정이며 모델 표시는 gemini-3.6-flash다. 이는 실제 생성 성공이나 모델 제공자 유효성 검증 완료를 뜻하지 않는다. 규칙 기반 미리보기·AI 생성 초안·검수 전·오류/미생성 상태를 구분한다.

### 뉴스와 검토 저장
뉴스는 3개 매체 RSS 조회, 최근 1/3/6/12개월 선택과 새로고침 방식이다. 관련성 검수 완료로 표현하지 않는다. 체크·검토 메모의 브라우저 로컬 저장 방식은 같은 기기·브라우저 범위이며 사용자 간 공유·서버 영구 보존은 확인되지 않았다.

### 분석 도움말
별빛 라마는 화면 수치·규칙을 이용하는 도움말로 구현되어 있다. 생성형 챗봇으로 설명하지 않으며 원인이나 여신 결정을 확정하지 않는다.

### 추가 정합성 확인
선정 5개 지표와 기존 공통 참고 규칙이 함께 응답한다. 공통 규칙·선정 지표의 역할과 집계 관계는 추가 대조가 필요하다. 사건 경고 0건을 미평가와 동일하게 해석하지 않는다. 웹 조회 조건이 연도를 전달하더라도 재무 패턴 모델의 실제 제공 범위는 2025 OFS 연구 스냅샷이며 다른 연도 제공 여부는 미확인이다.

### 연계 문서 상태
이 개정은 기획안 v2.5다. 기존 PRD v0.0.8·요구사항 v0.0.9·기능명세 v0.0.8·WBS v1.6·테스트 v0.0.4에는 이전 확률 모델·v2.3 잔존 설명이 있어 전체 정합성 보완은 진행 중이다. 이 기획안 발행을 연계 문서 전체 최신화 완료로 기록하지 않는다.
