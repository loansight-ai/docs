# LoanSight AI

제조·건설·도소매·부동산 임대 4개 업종의 재무·공시를 연결해 기업금융 담당자의 검토를 돕는다. 장비·물품 렌탈은 제외한다. OFS가 기본이며 CFS는 구분된 비교 자료다. 정량 징후 → 관련 주석 → 원인 후보 → 원문 근거 → 추가 질문으로 연결한다. 공식 여신 판단·내부 등급은 담당자가 수행한다.
