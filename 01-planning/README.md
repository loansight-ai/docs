## 문서 기준과 게시 이력

기획안 v2.0·요구사항/PRD/기능명세서 v0.0.4·WBS v1.1을 기준으로 한다. 대상은 제조·건설·도소매·부동산 임대 4개이며 장비/물품 렌탈은 제외한다. 12개월 상환·연체 위험 사건 예측과 6개 판단 축·경고/주의/관찰·기존 N-S04 위험 패널·공통/업종 주석 추출/검출 상태를 연결한다. 기능 검증 15곳·정답지 5곳, 임계값·현직자 확인·모델 수용/보류 등 미정 20개는 임의로 확정하지 않는다.

범위·표본 표현이 충돌하면 요구사항의 명시적 10/23 팀 결정(4개 업종 확정·렌탈 제외·15/5 논의 필요)을 우선한다. 원문 DOCX/XLSX는 수정하지 않고 바이트 그대로 보관한다. 버전 숫자를 기획안 v2.0에 맞춰 일괄 변경하지 않으며 각 문서의 독립 버전과 게시 개정일을 구분한다.

## 확인 방법

- [정합성 점검 결과](alignment-check.md)에서 전수 비교 범위·충돌 처리·미정·실제 검증의 차이를 확인한다.
- [원문과 버전 명세](version-manifest.json)에 각 원문 SHA256과 문서/행 범위를 기록한다.
- 원문 DOCX/XLSX/MD는 [sources](sources)에 바이트 그대로 보관한다. GitHub의 Markdown은 열람용이며 미정·검토 상태를 임의 변경하지 않는다.
- 노션 팀 메모·댓글·작업 본문은 운영 기록이다. 이번 게시에서는 수정하지 않는다. 실제 상태가 이후 변경되면 원문 버전과 운영 기록의 차이를 따로 확인한다.
- 화면/API/모델/계정 코드·수용 기준은 아직 미정인 부분이 있으므로 “문서 게시”를 “구현/승인 완료”로 해석하지 않는다.
