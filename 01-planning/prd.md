## 1 목적과 제공 범위

은행 기업금융·여신심사 담당자가 재무 변화와 공시 주석의 위험 근거를 연결해 어디를 먼저 보고 무엇을 추가 확인해야 하는지 파악하도록 돕는 웹 서비스다. 최종 대출 판단과 내부 등급은 담당자가 수행한다.

제조·건설·도소매·부동산 임대 4개 업종을 대상으로 하며 장비·물품 렌탈은 제외한다. 공시 확보가 가능한 상장사를 우선한다. 비상장 직접 입력·확장 기능은 출처와 제공 범위를 구분한다.

## 3 데이터와 계산 기준

별도재무제표(OFS)를 기본 분석 기준으로 사용하고 연결재무제표(CFS)는 구분된 비교 자료로 보존한다. 기간·통화·단위·누적/당분기·정정 여부를 맞추며 동일 추세 안에 OFS와 CFS를 섞지 않는다. 자료가 없으면 미확보를 표시한다. 회계처리 차이와 출처·기준일을 함께 표시한다.

회사·보고서·공시/수집일·정정 관계·OFS/CFS·통화·단위를 보존한다. 미확보·계산 불가·추출 실패를 0이나 정상으로 바꾸지 않는다. 직접 입력은 자동 수집과 구분하고 출처·기준일을 남긴다.

## 4 기능 범위와 ID 연결

### N-R01 기업·업종 범위

공시·재무 확보가 가능한 상장사 우선(코넥스는 상장시장으로 구분). 대상 업종은 제조·건설·도소매·부동산·임대 4개로 하고 운수·창고는 제외한다. 업종은 DART 업종코드 기준 매핑표로 정하며, 부동산·임대는 부동산 임대로 한정한다. 장비·물품 렌탈, 금융·보험, 지주회사, 스팩, 부동산 관리·중개는 대상에서 제외한다.

범위: 필수 · 확인할 사항: N-U02: 세부분류 적용 수준·기업·기간 미정. 업종별 상장사 수 집계로 표본 확인 필요

### N-R02 기업·기간·회계 범위 선택

기업을 식별하고 업종명(코드)·서비스 업종·세부분류·적용 기준(건설/부동산 임대 등)을 함께 표시한다. 보고 기간, 연결/별도, 결산월을 표시한다. 담당자가 업종을 바꾸면 변경 사유와 근거를 기록하고 바뀐 기준으로 다시 분석한다.

범위: 필수 · 확인할 사항: N-U02·N-U15: 기본 기간, 업종 변경 권한·기록 방식 미정

### N-R03 공식 원천과 출처 추적

OpenDART 기업개황·공시검색·전체 재무·원본 파일을 수집하고 기업 업종·접수번호·공시일·수집일·원문 위치·정정 버전을 저장한다. 사업보고서 원문은 목차 단위(I.1 신용등급, II 사업의 내용, III 주석, IV.4 유동성·자금조달, IV.5 부외거래, V.1 외부감사, XI.2~4 우발부채·제재·작성기준일 이후)로 저장해 주석 자동 추출(N-R41·N-R42)의 입력으로 쓴다.

범위: 필수 · 확인할 사항: API 실제 확보 범위·재시도·보관 정책 미정

### N-R04 비교 기준 표준화

별도재무제표(OFS)를 기본 분석 기준으로 사용하고 연결재무제표(CFS)는 구분된 비교 자료로 보존한다. 기간·통화·단위·누적/당분기·정정 여부를 맞추며 동일 추세 안에 OFS와 CFS를 섞지 않는다. 자료가 없으면 미확보를 표시한다. 회계처리 차이와 출처·기준일을 함께 표시한다.

범위: 필수 · 확인할 사항: 정정 적용·분기 변환 세부 정책, 회계처리 차이 판정 규칙 미정

### N-R05 계정·결측·정합성 관리

표준계정 ID 우선, 없으면 계정명으로 매핑한다. 계정 사전에 비율 계산 필수 계정을 포함한다: 매입채무, 단기·장기차입금, 유동성장기부채, 사채, 리스부채, 이자비용, 계약자산·계약부채, 투자부동산, 임대보증금·임차보증금, 유형자산 취득, 배당금 지급, 재고자산 평가·감모손실. 결측·0·미확보·추출 실패·비교 불가를 구분하고 자산=부채+자본, 합계·부호·단위를 검사한다.

범위: 필수 · 확인할 사항: 계정 사전·필수 계정 누락·단위·허용 오차·실패 상태 기준 미정.

### N-R06 직접 입력과 출처 기록

비상장·스타트업의 공시 조회 가능성을 먼저 대조한다. 직접 입력값은 출처·기준일을 기록하며 자동 수집값과 구분한다.

범위: 필수 · 확인할 사항: 입력 필드·저장·확인 기준 미정

### N-R07 핵심 재무 대시보드

영업이익을 우선 배치하고 비율을 유동성·레버리지·활동성·수익성·성장성 5개 묶음으로 표시한다. 공통 핵심 비율은 유동비율·부채비율·매출액영업이익률·총자산영업이익률·이자보상비율로 한다. 업종별 강조 지표: 제조(원가율·재고일수·현금전환주기·EBITDA), 도소매(매출총이익률·현금전환주기·매입채무일수), 건설(계약자산·선수금 제외 부채비율·차입금의존도), 부동산 임대(EBITDA·EBITDA 이자보상배율·차입금÷투자부동산). 감가상각·무형상각·사용권자산 중복을 점검한다. 기획안 v2.1의 수익성·안정성·활동성·성장성·현금흐름 관점을 함께 연결하고, 지표의 당기 값·최근 3~5개년 변화·동종 업종 위치·위험 사건·복합 징후를 구분한다.

범위: 필수 · 확인할 사항: N-U11: 회전율 분모 기준 미정. 계정 확보율 확인 후 표시 지표 확정

### N-R08 영업이익 변동 분해

영업이익 증감의 금액 기여도 = 매출 증감 - 매출원가 증감 - 판관비 증감. 설명되지 않는 차이는 기타·조정 차이로 표시한다. 회계 분해를 사업상 원인으로 단정하지 않는다. 업종별로 강조 항목을 달리한다(제조: 원가율, 도소매: 매출총이익률). 매출원가가 없는 성격별 손익계산서는 분해 불가 사유를, 임대수익이 기타수익에 있는 회사는 분해가 불완전함을 표시한다.

범위: 필수 · 확인할 사항: 계정 예외·잔차 허용 기준 미정. 성격별 손익계산서 비율 확인 필요

### N-R09 현금흐름과 특수 분모 처리

영업이익과 영업활동현금흐름의 차이를 운전자본(매출채권·재고·매입채무)·감가상각으로 설명한다. 현금흐름 비율(영업CF÷유동부채, 현금보상비율)과 현금흐름표 부실징후(단기차입으로 장기부채 상환, 과다 배당)를 점검한다. 업종 예외: 건설은 계약자산 증감을 표시한다. 0/음수 분모·적자 전환은 금액 차이와 상태로 표시한다.

범위: 필수 · 확인할 사항: N-U13: 이자비용 확보 방식 미정. 차트·계정 예외 기준 미정

### N-R10 비교 가능한 업종 분포

같은 기간·OFS/CFS·회계 기준의 동종 기업 분포·중앙값과 자사 과거 추세를 비교한다. 비교 가능한 기업 수가 부족하면 상위 분류 또는 비교 보류를 표시하며 부족한 자료를 전체 업종 대표로 제시하지 않는다. 한국은행 산업평균은 연도·모집단 차이를 표시한 참고 자료로 구분한다.

범위: 필수 · 확인할 사항: N-U06·N-U16: 비교군 최소 수, 산업평균 사용 범위·연도 시차 미정

### N-R11 소송·보증·담보 구조화

유형·상대방·금액/통화·진행 상태·기준일·원문 위치를 추출한다. 보증 제공/수취, 담보 소유/제공 대상, 진행/종결, 한도/잔액을 구분한다. 업종별 우선 추출 항목을 둔다: 건설(PF 지급보증·책임준공·채무인수 약정), 부동산·임대(담보 제공 자산, 투자부동산 평가 방식·공정가치), 공통(차입금 명세의 만기·금리, 재무약정). 조건부 의무(자금보충·채무인수·책임준공·매입확약·연대변제)와 기한이익상실 트리거(신용등급 하락 조건·금액)를 별도 유형으로 추출한다. 검색어·추출 범위는 N-R41·N-R42를 따른다.

범위: 필수 · 확인할 사항: N-U04: 코드·추출 확인 절차 미정. 업종별 우선 항목 현직자 확인 필요

### N-R12 주석 검수와 공통 재사용

표·본문 중복, 단위·부정 표현을 검수한다. 금액 미기재·미확보·추출 실패를 0으로 대체하지 않는다. 정합성을 확인한 구조화 결과를 요약·모델 입력에 공통 활용한다. 미검출은 '없음'으로 처리하지 않고, 원문에 '해당사항 없음'이 기재된 경우만 '공시상 없음'으로 저장한다. 일반 담보·차입약정은 우발부채로 자동 확정하지 않는다.

범위: 필수 · 확인할 사항: N-U04: 확인 승인·버전 기준 미정

### N-R13 근거가 있는 요약

확인된 사실/원문 근거/해석과 한계/추가 확인 형식으로 작성. 보고서·주석명과 원문을 연결. 숫자·비율은 코드 계산. 검색 없음과 해당 사항 없음, 회사 주장과 확인 사실을 구분한다.

범위: 필수 · 확인할 사항: N-U07: LLM·검수 목표치 미정

### N-R14 내부 자료 확인과 최종 판단

외부 공시로 확인 못하는 내부 거래·담보 평가·상환 약정은 추가 확인으로 남긴다. 초기 은행 내부 자료 수집·전송 제외. 대출 승인·거절·내부 등급은 담당자가 결정한다. 업종별 징후 단계(N-R39)는 담당자 확인 순서용이며 은행 자산건전성 분류·내부 등급·여신 결정을 대신하지 않는다.

범위: 필수 · 확인할 사항: 확인 안내 문구·접근 정책 미정

### N-R15 관련 기사 보완

기업 식별·실적 비교 기간을 기준으로 동명이인·단순 언급·중복을 제거하고 관련성 재검수. 기사 날짜·출처·링크를 표시. 품질/수집이 어려우면 링크만 제공한다.

범위: 보완 · 확인할 사항: N-U07: 후보 매체·수집 조건·품질 미정

### N-R16 12개월 상환·연체 위험징후 확률 목표

범위: 필수 · 확인할 사항: 학습·확인·확률 결과 모두 미확인

### N-R17 상환·연체 위험 사건 정의와 원천

라벨 사건은 공시로 확인되는 원리금 연체·기한이익상실, 어음·수표 지급거절, 회생절차·채권은행 관리절차 개시신청, 감사의견 비적정·계속기업 불확실성 기재로 한다. OpenDART 주요사항보고서 API·감사보고서·공시 원문으로 최초 발생일·접수번호를 대조하고 사건 유형별 심각도를 함께 기록한다. 관리종목 지정·상장폐지 등 상환·연체와의 관련이 확인되지 않는 사건은 라벨에 넣지 않는다.

범위: 필수 · 확인할 사항: N-U01: 사건 유형·심각도·원천 제공 범위·공개/발생 시점·추적 종료 기준 미정.

### N-R19 재무·주석 특징 결합

영업이익률·부채/자산·유동비율·OCF/부채·변동과 정합성을 확인한 소송/보증/담보 특징을 결합. 금액/자산·전기 변화, 업종·규모·회계 기준, 결측 상태를 관리한다. 존재 자체를 부실로 간주하지 않는다. 후보 변수에 상환능력(차입금의존도, 단기차입 비중, 이자보상비율, 현금보상비율)과 운전자본(현금전환주기 변화)을 추가한다. 업종은 구분값으로 넣고, 업종마다 의미가 다른 변수는 업종 내 상대값 사용을 검토한다. 계정 확보율이 낮은 변수는 제외한다. 업종별 주석 추출 항목(PF 보증 만기 구간·조건부 의무 유형, 1년 내 만기 차입 비중, 리스부채, 담보제공 비율, 기한이익상실 조항, 감사의견·신용등급 변화)을 후보 변수에 추가한다. 활동성·성장성·현금흐름 지표(회수기간·회전기간·순운전자본회전율·매출 증가 대비 채권/재고 증가 차이·FCF/차입금·ROIC)와 개별/복합 위험 플래그를 후보 특징으로 연결한다. 모델 제공 조건과 내부 품질 관리는 별도 문서에서 관리한다.

범위: 필수 · 확인할 사항: N-U05: 모델 후보·결측 처리·서비스 제공/보류 조건 미정.

범위: 필수 · 확인할 사항: N-U05: 모델 후보·결측 처리·서비스 제공/보류 조건 미정.

### N-R24 규칙 기반 추가 확인

확인 규칙을 공통 절대 기준(자본잠식, 영업CF 유출 등)과 업종 기준으로 나눈다. 업종 기준은 건설·부동산 임대별로 맞지 않는 공통 기준의 상태를 낮추고 업종 지표로 대체한다(예: 부동산 임대의 부채비율 → 차입금÷투자부동산, 이자보상배율 → EBITDA 이자보상배율). 낮춘 항목은 숨기지 않고 '[업종 기준]'과 이유를 표시한다. 모든 규칙은 ID·수치·근거·버전을 갖고, 임시 팀 기준임을 표시하며 은행 공식 기준으로 제시하지 않는다. 자동 판정 결과는 경고·주의·관찰 징후 단계(N-R39)와 규칙 ID로 연결한다.

범위: 필수 · 확인할 사항: N-U06·N-U12: 규칙 수치(30%·50%·1.5배·70%, 현금전환주기 +30일 등) 근거·검토 미정

### N-R32 업종 판정·매핑

OpenDART 기업개황 업종코드를 업종 매핑표(DART 기준)로 서비스 업종·세부분류·처리(대상/별도/제외)·적용 기준에 연결하고, 코드사전으로 업종명을 표시한다. 가장 긴 접두 코드로 판정하며 미분류는 그대로 표시한다. 겸업 회사는 사업보고서 부문별 매출로 '복합'을 표시하고, 수동 변경은 근거와 함께 기록한다.

범위: 필수 · 확인할 사항: N-U15: 복합 판정 비중·수동 변경 권한 미정

### N-R33 재무비율 산식 사전

유동성·레버리지·활동성·수익성·성장성·현금흐름 비율의 산식, 분자/분모 계정, 단위, 표시 형식, 기말/연평균 기준을 한 곳에서 정의하고 화면·메모·모델이 같은 정의를 쓴다. 이자보상비율처럼 근사 계정(금융원가 등)을 쓰면 근사임을 표시한다. 기획안 v2.1의 11개 보완 산식과 기존 비율 정의를 하나의 사전에서 관리한다. 산식이 없는 정상영업현금흐름은 표준 지표로 확정하지 않는다. 증가율은 전기 값이 0/음수이면 상태와 금액 차이를 우선 표시한다.

범위: 필수 · 확인할 사항: N-U11: 연평균/기말 기준, N-U13: 이자비용 대체 기준 미정

### N-R34 차입금·상환능력 분석

총차입금(단기차입금·유동성장기부채·장기차입금·사채)과 차입금의존도, 단기차입 비중, 이자보상비율, EBITDA 이자보상배율, 현금보상비율, 금융비용부담률을 계산한다. 부동산·임대는 임대보증금을 반환 의무가 있는 부채로 별도 표시한다. 리스부채 포함 여부를 표시한다.

범위: 필수 · 확인할 사항: N-U13·N-U14: 이자비용·임대보증금 처리 미정

### N-R35 영업순환·운전자본 분석

업종별 영업순환 단계에 맞춰 재고·매출채권·매입채무 회전일수와 현금전환주기를 계산하고 전기 대비 변화를 표시한다. 건설은 계약자산(미청구공사)·계약부채(선수금) 증감을 함께 본다. 매출원가가 없으면 계산 불가 사유를 표시한다.

범위: 필수 · 확인할 사항: N-U11: 회전일수 기준, N-U12: 변화 기준치 미정

### N-R36 재무적 부실징후 점검표

기획안 v2.1의 23개 RISK 항목을 위험 영역별 초기 탐지 후보로 관리한다. 자동 계산/주석 확인/외부 확인을 구분하고 값·추세·근거·추가 확인을 연결한다. 초기 임계값은 업종·사업모델에 따라 조정이 필요한 후보이며 공식 은행 기준으로 제시하지 않는다.

범위: 필수 · 확인할 사항: N-U12/N-U17: 23개 RISK 후보의 업종·기간·임계값 적용 기준 미정.

### N-R38 업종별 상환·연체 위험징후 지표

기획안 v2.1 판단 관점 10개(상환재원·유동성/만기·재무구조·우발/부외·외부평가·담보/회수·수익성/원가·운전자본/활동성·성장의 질·투자/자본효율)를 공시 지표와 주석 근거에 연결한다. 업종별 핵심·보조·왜곡 지표를 구분하고 담당자 확인 순서를 지원한다. 공식 건전성 분류나 내부 등급을 산출하지 않는다.

범위: 필수 · 확인할 사항: N-U12·N-U17: 지표별 기준값·현직자 확인 미정. N-R07 업종별 강조 지표와 중복 정리 필요

### N-R39 징후 단계 판정과 표시

업종별 지표와 주석 추출 결과로 경고·주의·관찰 3단계를 판정한다. 경고 예: 감사의견 비적정·계속기업 불확실성, 완전자본잠식, 어음·수표 지급거절·회생절차 개시신청 공시, 기한이익상실 사유 발생, 이자보상비율 1배 미만 3년 연속. 주의 예: 부분자본잠식, 당기 이자보상비율 1배 미만, 흑자인데 영업CF 2년 연속 음수, 1년 내 만기 차입금 > 현금성자산+영업CF, 신용등급 하향·부정적 전망, 제공 보증·조건부 의무의 자기자본 대비 급증. 관찰: 업종 중앙값 대비 열위·악화 추세. 경고는 상단 고정·원문 확인 필수, 주의는 확인 항목에 추가한다. 단계는 담당자 확인 순서용이며 건전성 분류·내부 등급을 대신하지 않고, 수치는 팀 가설로 표시한다. 개별 지표의 경고와 여러 영역이 동시에 악화된 복합 경고를 분리하여 표시한다. 복합 위험 7유형의 조건 조합·판단 근거·담당자 질문을 제공하며 단일 신호와 중복 집계하지 않는다.

범위: 필수 · 확인할 사항: N-U17: 조건 수치·기간·현직자 검토 미정

### N-R40 업종별 위험징후 패널·시각화
