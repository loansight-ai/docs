# LoanSight AI 발표·시연 준비 계획

기준: 기획안 v2.0·요구사항/PRD/기능명세서 v0.0.4·WBS v1.1 · 게시 개정일: 2026.10.24 · 검토·승인자: 미정

[전체 기획 문서](../01-planning/README.md) · [미정 질문](../01-planning/requirements.md#미정-질문-20개)

WBS 6.1~6.5 계획 기간은 11/03~11/04이며 최종 제출/발표 계획은 11/05다. 실제 교육 마감 일치는 N-U09로 확인한다. 이 문서는 발표 준비 계획으로 최종 PPT·영상 제작/발표 완료 기록이 아니다.

## 자료 현황

| 자료 | 내용/연결 | 상태 |
| --- | --- | --- |
| 최종 PPT/대본 | 4개 업종·최신 위험 사건/패널/추출·검증 한계, WBS 6.2/6.5 | 최신 범위 반영·파일 확인 필요 |
| 시연 영상/예비 자료 | N-S01→N-S04→N-S05→N-S08, WBS 6.3 | 제작/검수 확인 필요 |
| 실행·데이터 안내 | 원문/모델/버전·의존성·실행 절차, WBS 6.1 | 실행 증빙 확인 필요 |

기존 로컬 기획 발표자료와 이번 v2.0 기준 최종 발표본을 구분한다. 이 저장소에서 최신 최종 PPT·대본·영상 실물의 게시/검증은 아직 확인되지 않았다.

## 발표 구성

1. 현업 문제·대상 사용자·인터뷰에서 나온 검토 불편
2. 제조·건설·도소매·부동산 임대 범위와 렌탈 제외
3. 재무/차입·상환/영업순환·실적 변동·회계 기준과 예외
4. 공통/업종 주석 추출·원문·검출 상태와 N-S04 규칙 패널
5. 향후12개월 상환·연체 위험 사건 목표, 시점/라벨·재무 기준/결합 모델 비교·보정
6. 실제 검증 결과와 표본·수용 미정·미검출 원인·사용자 실험 한계
7. 구현 상태와 기대효과·실증 결과·후속 확장·역할 구분

## 시연 시나리오와 체크

기업/업종/기간 선택 → 핵심 재무·변동 → 주석/4개 검출 상태 → 규칙 경고·주의·관찰/지표 추세/근거 → 검증된 모델 확률·보류 표시 → 담당자 체크·검토 메모 수정/복사. 네트워크·추출 실패·표본 부족의 대안 화면/예비 자료를 준비한다.

실제 시연 code SHA·데이터/원문·모델 버전·시연자·재생/접속 증빙은 리허설 시 기록한다. 미정 목표치·가설 임계값·15/5 표본을 확정/달성으로 표시하지 않는다.
