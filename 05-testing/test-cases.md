- 검증 범위:

## 테스트 케이스

| ID | 요구사항·기능 ID | 사전 조건 | 입력·절차 | 기대 결과 | 실제 결과 | 판정 | 증빙·오류 Issue |
|---|---|---|---|---|---|---|---|

ID 예시: `TC-001`. 판정은 미수행 / 통과 / 실패로 기록합니다.
예상 결과를 실제 결과로 복사해 검증한 것처럼 표시하지 않습니다.

## AI 결과 검증
AI를 사용하는 기능은 출처·수치 일치, 근거 없는 해석, 실패 응답 및 반복 실행 시 차이를 검토합니다.
사용할 검증 데이터와 기준은 주제 선정 후 확정합니다.
