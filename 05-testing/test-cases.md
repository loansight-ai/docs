## 검증 대상 기록

- code 커밋 SHA·실행 환경/의존성·데이터 버전·모델 버전·검증자: 실행 시 기록, 현재 미정
- 기능/정답지 15/5는 논의 필요. 계정 확보 업종별 5개 이상 계획·기획안 인용 추출40개사·모델 표본·사용자 실험을 구분한다.
- 징후 임계값·현직자 확인·추출/성능 수용 기준은 N-U 질문 결정 전까지 통과 기준으로 고정하지 않는다.
