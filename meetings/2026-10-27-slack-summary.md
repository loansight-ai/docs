## 💬 안건별 논의

### 1. 분석 기준과 주석 활용 · 진행 중

- 현직자 의견 전달에는 웹 이용 제약, 기업이 제공한 자료·거래 신뢰 활용, 연결보다 별도재무제표를 많이 본다는 내용이 있었다. 특정 현장의 전달 의견이며 모든 은행의 운영 기준으로 일반화하지 않는다.
- 김동혁은 OFS 중심으로 분석 기준을 조정하고 2024·2025년 자료를 추가 수집했다고 보고했다. 기존 CFS 분석은 비교용으로 보존하며, 상관분석·집단 차이 검정·전년 대비 분석과 패널 자료의 반복 관측·연도 충격을 검토 중이다. 실제 연체 예측력은 미검증이다.
- 업종별 주요 위험징후 지표의 분류에는 추가 검증이 필요하다고 명시됐다. 정형 재무제표 분석을 먼저 진행하고 주석 구조화는 분석 단계에서 보류하며 요약에 활용한다는 방향이 제시됐다.
- 이후 업종별 공통 주석 항목을 우선 요약하고 없으면 전체 주석 요약으로 전환하자는 아이디어가 나왔다. 확정된 추출·요약 규칙은 아니다.

### 3. 주석을 통한 지표 확보 · 자료 검토

- 김동민의 자료는 연결 우선 재무자료와 원문 주석의 회사·연도 218건을 대상으로 한 표본 점검이다. 전날 소수 사례의 눈검사와 구분된다.
- 금융원가의 이자비용, 성격별 비용·현금흐름 조정의 감가상각비를 우선 확보하고 차입 만기·계약자산/부채·리스·PF 항목을 뒤이어 점검하는 순서를 제안한다.
- 자료 보고상 이자비용 기준 이자보상비율의 확보 가능 비중은 제조 2%→96%, 도소매 9%→93%, 건설 7%→89~91%로 늘었다. 이는 항목명 인접 금액 탐색 등의 표본 규칙에 따른 보고치이며 자동 추출 정확도나 위험 예측 성능이 아니다.
- 부동산 임대의 만기 재분류, PF의 한도·보증액·대출잔액·단위·중복, 회사·연도별 평가모형 차이가 남는다. 현금 이자지급과 손익 이자비용은 정의가 달라 혼용 기준을 확인해야 한다.
- 자료의 ‘언급 없으면 0/해당없음’ 처리 일부는 요구사항의 ‘명시적 없음만 공시상 없음, 미검출≠없음’과 충돌한다. 적용 전 원문 근거와 상태 정의를 검토해야 한다.
- 렌탈을 포함한 5분류 확보율 자료와 렌탈 제외 4업종 요구사항의 범위 차이도 남는다.

### 5. 뉴스 요약과 대안신용평가 · 검토 제안

- 오준탁의 뉴스 문서는 경제지·통신사·크레딧 매체 6곳 후보, 강한 포함 조건을 우선한 키워드 필터와 AI 2차 분류, 날짜·수치·기업명 검증을 제안한다.
- 문서의 삼성전자 제목 28건 시험은 27건 일치라고 보고하지만 2건은 가상 제목이며 선정 표본이다. 독립 재현·실서비스 정확도 검증이 아니다. 기사 예시의 재무 수치와 기업 사실은 여기서 검증하지 않아 전재하지 않았다.
- 유료 본문 미확보, 출처 밖 중요 기사 누락, 동명·계열사 혼동, 오래된 기사 날짜 문제를 명시했다. 매체·수집 기간·API 조건·사실과 해석 표시·기사 누락 기준은 팀 결정이 필요하다.
- 대안평가 논의는 비외감 중소법인·개인사업자 등의 정보 부족을 대상으로 매출·세무·납부·고용·계좌 흐름 등 11범주를 정리했다. 공공정보 후보와 동의·내부 자료가 필요한 확인 항목을 나눴으나 API별 제공 범위·무료 여부는 미확인이다. 현재 MVP의 자동 수집 확정 범위로 보지 않는다.

### 6. 개발 진행과 수행일지 · 보고

- 서종원은 아키텍처·MQ/SSE·사용자 세션 설계, 재무/주석 화면·API/DB 환경·비동기 처리·세션 복원 연동과 개발 환경 오류 수정을 보고했다. 실시간 개발 주소가 공유됐으나 접속·배포·운영 검증은 수행하지 않았다.
- 오준탁은 DB 연결 전 예시 데이터로 동작하는 9개 화면·종합 리포트 시연판을 만들었다고 보고했다. 서종원의 개발 진행과 별개 보고이며 실데이터 연동 완료로 합치지 않았다.
- 공통 재무지표×40개사 계산, ECOS 비교, 재무제표 구성 차이, API 연결 등이 후속 작업으로 보고됐다. 기존 베타 분석 결과물과 미수행 공통 지표 계산은 구분해야 한다.
- 수행일지는 공유 드라이브 업로드 완료라고 보고됐다. 외부 드라이브 원본과 해당 링크의 서비스 상태는 직접 확인하지 않았다.
- **근거:** [수행일지 전체](https://kb-bridge12.slack.com/archives/C0C8L1KGVN1/p1793085285671109) · [개발 주소 공유](https://kb-bridge12.slack.com/archives/C0C8L1KGVN1/p1793088795293209)

## ❓ 미결 사항

- OFS 분석·CFS 우선 수집/조회·모델 기본값을 어떤 기준으로 통일할지, 업종별 기준과 정량 지표의 실제 예측력을 어떻게 검증할지 미정이다.
- 주석 미검출·명시적 부재·0·해당없음의 구분, PF와 만기 표의 수치 검산, 렌탈 포함 자료의 활용 범위를 확인해야 한다.
- 기획안·요구사항·WBS의 기준 버전·담당·일정·완료 기록과 요약 셀 오류를 대조해야 한다. 문서의 계획을 팀 합의·구현 완료로 바꾸지 않는다.
- 뉴스 매체·이용 조건·분류와 요약의 검수 기준, 대안평가 API 제공 범위·동의 조건은 미정이다.
- aireport-sample.pdf(10.6MB)는 파일 읽기 도구의 10MB 제한으로 2회 실패했다. 공유 사실만 반영했으며 내부 구성·페이지 내용은 미확인이다. [공유 원문](https://kb-bridge12.slack.com/archives/C0C8L1KGVN1/p1793061491042199)
