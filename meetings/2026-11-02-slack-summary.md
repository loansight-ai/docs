## 💬 안건별 논의

### 1. 위험징후 기준과 역할 분리 · 연구안 정리

- 업종별 지표 선정은 도메인 근거, 단계 경계는 데이터 점검으로 나누자는 의견이 나왔다. 기존 분포 기준에서 주의가 과다 발생하고 이자보상 근사치가 경고에 집중된다는 점검 보고가 있었으나, 예측 성능이나 공식 은행 기준으로 검증된 결과는 아니다.
- 오전에는 2025년만 판정하는 방향이 제시됐다. 오후 전달안은 **조회 보고서 연도와 2025년 분류 기준을 분리**하고, 다른 연도는 해당 연도의 OFS 원자료로 다시 계산하도록 구체화했다. 2025년 결과 CSV를 다른 연도 결과로 재사용하지 않는다. 과거 시점의 예측·백테스트로 해석하지 않는다.
- 재무 입력의 적용 가능성 확인 → 절대 조건 → 상대 구간 순서다. 결측·기간/계정 불일치는 보류, 확인된 무차입은 해당 차입비율만 해당 없음으로 구분한다. 미해당은 정상·안전 판정이 아니다.
- 재무 절대 조건은 주의(절대)로, 불리한 표본 사분위는 주의(상대)로 표시한다. 확인된 사건·지속 조건은 독립 경고 경로다. 오후 중간 메시지에 절대 조건을 경고라고 적은 표현도 있으나, 말미 정리와 최종 전달 자료에서는 주의(절대)로 구분했다.
- 감사의견 한정·부분자본잠식은 주의로 분리하고, 3년 연속 이자보상 조건은 동일 기준 3개년 확인 전 보류한다. 사건 미확인은 경고 0건이 아닌 미평가·보류다.
- **원문:** [기준 검토 스레드](https://kb-bridge12.slack.com/archives/C0C8L1KGVN1/p1793580228207989), [최종 전달](https://kb-bridge12.slack.com/archives/C0C8L1KGVN1/p1793607185911369)

- 제조는 현금 창출·이자 부담·CCC·차입 부담, 도소매는 CCC·재고·마진·부채와 현금 창출, 건설은 현금/부채·이자·계약자산 변화·만기 부담을 중심으로 제안했다. 조건부·보조·관찰까지라는 사용 역할을 기업 위험 단계와 혼동하지 않는다.
- 건설의 작은 유효 표본·넓은 경계 불확실성, 도매/소매 합본의 사업모형 차이, CAPEX·공사미수금 대용 계정 한계를 유지했다. 개발비·수주잔고 등 미확보 자료를 임의로 채우지 않는다.
- 부채총계에 이미 포함된 리스를 다시 더하지 않도록 명칭·산식을 통일하자는 쟁점이 남았다. 연구 보고서의 부채비율과 웹의 차입금·리스 기반 지표를 같은 것으로 단정하지 않는다.
- 재표집 경계 안정성은 실제 연체 확률·예측 정확도가 아니다. 외부 지침·논문·ECOS 관련 주장은 문서·발언의 근거 설명이며 이번 회의록 작업에서 외부 원문을 독립 재검증하지 않았다.

### 3. 개발 전달 패키지와 화면 연결 · 전달 완료 보고

- ZIP의 안내문·판정 코드·테스트 코드·규칙/목록·검증 기록을 읽고 CSV 구조와 행 수를 확인했다. 연구 기준 15개 업종×지표 조합, 카드 후보 29개, 판단 축 6개, 사건 규칙 9개와 기업별 결과를 담는다. 후보 목록 전체를 자동 판정으로 활성화하는 의미는 아니다.
- 코드는 수집·계정 매핑을 수행하지 않는다. 동일 기간·OFS·단위·계정 구성 검증을 마친 입력이 필요하며 결측을 0으로 바꾸지 않는다. 기존 결과 CSV와 새 함수의 예외 처리 적용 범위도 구분한다.
- 카드와 전체 징후 목록은 같은 결과를 공유하고 CCC/구성 지표·공통 CFO 음수 등 같은 원인을 중복 합산하지 않는 안이다. 상환재원·유동성/만기·재무구조·우발/부외·외부 평가·담보/회수 축을 제안했으며 담보/회수 자동 기준은 미확보다.
- 동봉 검증 기록은 작성 측의 테스트 통과 보고다. 이번 작업에서는 첨부 코드를 실행하거나 실제 서비스 전체 결과를 재현하지 않았다. 카드 최종 개수·순서·추가 지표 활성화와 사건 원문 검증은 남아 있다.
- **첨부 근거:** [전달 ZIP·README](https://kb-bridge12.slack.com/archives/C0C8L1KGVN1/p1793607185911369)

### 4. 웹 디자인·구현·성능과 데이터 구조 · 진행 보고

- 디자인 비교 이미지 9장은 기업 검색, 재무 요약, 실적/현금흐름, 위험징후, 주석 근거, 예측, 뉴스, 검토 메모, 상세 모달을 기존/1차/2차 시안으로 나눴다. 1차는 색·모서리 조정, 2차는 큰 제목·여백·둥근 카드 중심의 재구성이며 기능·예측 결과의 검증 자료는 아니다.

- 오준탁은 정렬·로딩·색인 최적화, 도소매 차트, 자료 없음 안내, 임대업 제외와 v1.3.2까지의 배포를 보고했다. 응답시간 단축·결과 차이 없음은 작성자의 측정 보고로 남기며 독립 재측정하지 않았다.

### 5. QA·발표·수행일지와 추가 논의 · 요청·공유

- 강사는 QA로 세부 동작을 다듬고 가독성·UI/UX에 현업 의견을 받아보며, 발표 자료에 강점·고민·해결 과정을 담도록 권했다. 각 파트 자료 정리는 당일 할 일로 공유됐다.
- 수행일지 스레드 제목은 261101이지만 댓글 작성 시각은 11월 2일이다. 이번 구간의 진행 보고로 반영했으며 공유 드라이브 업로드 완료 발언을 확인했다. 실제 드라이브 파일은 열지 않았다.
- 이전 뉴스 스레드에는 요약 기능 참고 논의 요청이 달렸다. 늦은 시각 비지도학습(이상탐지·클러스터링) 제목만 새로 올라왔으며 모델 결과·구현 완료를 주장할 본문은 없다.
