## 💬 안건별 논의

### 1. 멘토링·인터뷰에서 주제 변경으로

오전에는 세 후보의 사용자·가설을 좁히고, 소규모 검증 후 고도화하라는 피드백이 공유됐습니다. WorkPulse는 고용 데이터의 확보 범위·표본 수·실제 유용성, EWS는 기업별 민감도 정의·기준 폭·선형 환산·공시 시차가 쟁점이었습니다. 오후에는 실적변동 원인 분석을 최종 주제로 기록했습니다. 전날 WorkPulse 선택을 과거 기록에서 지우지 않고 오늘 변경으로 구분합니다.

오준탁이 공유한 현직자 답변은 영업이익 우선 확인, 감가상각·현금흐름 탐색의 어려움, 시각화·심사 항목 작성과 체크 지원의 필요를 담았습니다. 뉴스까지 찾아볼 여유가 부족하다는 의견도 나왔습니다. 이는 인터뷰 의견이며 전체 은행 업무의 일반적 사실이나 회계처리 검증 결과로 확장하지 않습니다.

오후 피드백은 업종 약 5개부터 구현, 주석의 소송·보증·담보 정보 요약, 외부 자료로 확인된 내용과 내부 추가 확인의 분리, 뉴스 관련성·누락 검증, 분석 차별화 보완이었습니다. 부도 확률 예측은 이때 검토 제안이었고 이후 기획안 v1.0에는 개발 범위로 포함됐습니다.

### 2. 첨부 기획안의 변화와 서비스 범위

| 자료 | 본문에서 확인한 내용 | 상태·한계 |
|---|---|---|
| 실적변동원인분석 v0.1.0 DOCX | 영업이익 중심 화면, 규칙 기반 체크포인트, 정형 메모·직접 입력, ECOS·공시 원문 확장 | 문서의 MVP v0.4 구현·18개 계산 테스트 언급은 작성자의 보고, 이번 작업에서 실행 검증하지 않음 |
| 재무나침반 v1.0 DOCX | 재무 변동·현금흐름·업종 비교, 주석 구조화·요약, 재무·주석 결합 부도 예측 | 개발·검증 계획, 구현·성능 완료로 보지 않음 |
| 발표 v1.0 PPTX·PDF | 14장, 문제→설계→8개 기능→WBS·역할·기대효과 | PPT 본문·노트와 PDF 본문·전체 페이지 시각 확인, 차트 수치는 가상 예시 |
| WBS v1.0 XLSX | 한눈에 보기·작업 관리·일정·완료 기준 4개 시트, 작업 ID·담당·기한·선행·근거 | 실행 초안, 시트에 적힌 상태와 실제 접수·구현 결과는 구분 |

최신안은 **은행 기업금융·여신심사 담당자**를 대상으로 영업이익·현금흐름의 변화, 공시·주석 근거와 추가 확인 사항을 연결합니다. 상장사를 우선 검증하며 코넥스와 비상장 기업을 구분합니다. 업종 후보는 제조·건설·도소매·운수/창고·부동산/임대이고 최종 목록은 자료 확보 후 확정할 계획입니다.

기본 데이터는 OpenDART 기업개황·공시검색·전체 재무제표·공시 원문입니다. 연결/별도·단위·기간·정정 버전을 맞추고 결측·0·조회 실패를 구분합니다. 영업이익 변동 분해는 회계상 금액 기여도이며 사업상 인과관계를 입증한 것으로 쓰지 않습니다.

필수 기능 7개는 기업 검색·업종 필터, 핵심 재무 대시보드, 실적 변동·현금흐름 분석, 주석 추출·요약, 재무·주석 결합 부도 예측, 확인 체크, 검토 기록 초안입니다. 관련 뉴스는 보완 기능이고 초기 예측 모델 입력에서 제외하는 계획입니다. 내부 자료 확인과 최종 여신 판단은 담당자에게 남깁니다.

### 3. 부도 예측 도입안과 검증 계획

v1.0은 공시 기준일 이후 **12개월 내 실제 부도 사건**을 목표로 재무지표 기준 로지스틱 회귀와 재무·주석 결합 모델을 같은 표본에서 비교하는 계획을 담았습니다. 소송 규모·상태, 지급보증 제공/수취, 담보와 한도/잔액을 구분해 구조화한 뒤 수치 변수로 만들고 원문과 연결합니다.

실제 사건일·관측 종료를 확인하고 회생·관리종목·상장폐지를 부도와 동일시하지 않으며 API 미조회만으로 정상 라벨을 주지 않는 원칙입니다. 시간 기준 분할·기업 중복·미래 공시 유입을 점검하고 PR-AUC·정밀도/재현율·Brier·확률 보정을 비교할 계획입니다. 표본 확보·학습·평가와 확률 산출은 아직 검증된 실적이 아닙니다.

기능 검증 15개 기업·상세 정답지 5개 기업과 모델 학습/평가 표본을 구분합니다. 업무 효과는 수강생 비교 실험과 현직자 피드백으로 확인할 계획이며, 예측 성능이나 시간 절감 효과를 미리 확정하지 않습니다. 외부 논문·API·회계기준 링크는 첨부 문서가 인용한 자료로만 기록하며 이번 작업에서 별도 검증하지 않았습니다.

### 4. 문서·일정·기존 기능의 확인 사항

WBS는 기획안 v1.0 정리와 이전 발표 v0.2 보존을 완료로 적고, v1.0 발표 반영 작업 1.8은 10/22~23 예정으로 남겼습니다. 같은 날 실제 공유된 발표는 v1.0·14장이므로 WBS의 버전·상태 갱신 여부를 확인해야 합니다. 기획안의 역할 분담은 초안이며 세부 담당·작업량은 팀 회의에서 확정하도록 적혀 있습니다.

기획안·발표의 일정은 10/22~23 범위/라벨 정의, 10/24~30 구현·모델 작업, 10/31~11/02 통합 검증, 11/03~04 발표 준비, 11/05 오전 9시 제출·발표입니다. 모두 계획이며 달력상 기한만으로 완료 처리하지 않습니다.

WorkPulse에서 분기·반기 조회, 보고서 신뢰 수준 표시, 시장 구분, 고용 지표의 소규모 연결 시험을 가져오자는 의견이 있었습니다. 이는 제안이며 모두 수용된 기능으로 적지 않습니다. 해당 댓글의 뉴스 제외 의견과 이후 v1.0의 뉴스 보완 기능도 공유 시점·문서 버전을 구분합니다.
