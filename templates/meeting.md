## 작성·검토 기준

- 제안, 확정된 결정, 미결 사항을 구분합니다. 실제로 없는 결정이나 수행 결과는 만들지 않습니다.
- 담당자와 기한이 명시되지 않았다면 미정으로 남깁니다. 기한은 가능하면 YYYY-MM-DD로 기록합니다.
- Slack 요약은 실제 수집 기간과 대화 참여자를 기록하고, 이전 스레드의 맥락과 새 댓글을 구분합니다.
- Slack 자동 요약에서 회의 준비가 해당하지 않으면 해당 없음으로 표시하고, 안건은 실제 대화 주제에서 추출합니다.
- 각 결정·할 일은 가능한 한 Slack 원문, 문서 또는 Issue 링크로 근거를 연결합니다.
- 할 일의 상세 진행 상태는 관련 Issue에서 관리하고, 회의록에는 회의 당시 합의와 확인 결과를 남깁니다.
- 자동 생성 회의록은 검토 전까지 초안으로 두고, 자동 생성 본문과 사람이 추가한 검토 메모를 구분합니다.
